# Project Manifest — ship.jsonc

**Location**: `.ship/ship.jsonc`
**Schema**: `ship.schema.json`

The project manifest declares providers, modes, module identity for publishing, dependencies, and exports.

## Top-level fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `$schema` | string | no | JSON Schema URL for editor autocompletion |
| `schema_version` | `"1"` | no | Schema version for forward-compatible migrations |
| `id` | string | no | Unique project identifier, auto-generated by `ship init` |
| `project` | object | no | Project-level settings |
| `harness` | object | no | Project-level overrides for the launch defaults consulted by `ship use --launch`. See [harness](#harness). |
| `module` | object | no | Package identity for registry publishing |
| `dependencies` | object | no | Registry dependencies |
| `exports` | object | no | Skills and agents available to consumers |

## project

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `name` | string | — | Human-readable project name |
| `providers` | array | — | AI provider targets: `claude`, `cursor`, `codex`, `gemini`, `opencode` |
| `provider_defaults` | object | — | Project-level provider settings inherited by all agents. Deep-merged with agent-level `provider_settings` (agent wins). Ship-managed keys (permissions, hooks, model, env) are excluded — use Ship's own fields. |
| `modes` | array | — | Named modes that filter active MCP servers, skills, rules, and hooks. See [Modes](#modes). |
| `skill_paths` | array | `["skills/"]` | Directories to scan for skills, relative to `.ship/`. First path wins on duplicate IDs. |

## harness

Project-level overrides for the user-KV launch defaults. Picked when the corresponding per-launch flag is absent on `ship use --launch`. Per-user preferences (e.g. `agent_session.auto_resume`) are intentionally not overrideable here — they stay in user storage so each contributor can set their own.

| Field | Type | Description |
|-------|------|-------------|
| `default` | string | Overrides the user-KV `harness.default` setting. Used when `--harness=X` is not passed. |
| `default_model` | string \| null | Overrides the user-KV `harness.default_model` setting. Used when `--model=X` is not passed. `null` clears any user-level value for this project. |

```jsonc
{
  "harness": {
    "default": "codex",
    "default_model": "opus"
  }
}
```

## module

Required for `ship publish`. The `name` doubles as the Git clone URL.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | yes | Package path, e.g. `github.com/owner/repo`. Pattern: `^[a-z0-9./_-]+$` |
| `version` | string | yes | Semver version (v-prefix optional). Must match a Git tag. |
| `description` | string | no | Human-readable summary |
| `license` | string | no | SPDX identifier, e.g. `MIT`, `Apache-2.0` |

## dependencies

Keys are package paths. Values are version constraints or objects:

```jsonc
{
  "dependencies": {
    "github.com/acme/toolkit": "^1.0.0",           // shorthand
    "github.com/acme/pinned": {                     // object form
      "version": "main",
      "grant": ["Bash"]                             // tool permissions
    }
  }
}
```

| Constraint | Type | Behavior |
|-----------|------|----------|
| `^1.0.0` | semver caret | `>=1.0.0, <2.0.0` |
| `~1.2.0` | semver tilde | `>=1.2.0, <1.3.0` |
| `1.2.3` | exact | Exactly `1.2.3` |
| `main` | branch | Tracks branch tip |
| 40-char hex | commit | Pinned to exact commit |

## exports

Only items listed here are installed by consumers. Paths are relative to `.ship/`.

| Field | Type | Description |
|-------|------|-------------|
| `skills` | string[] | Skill directory paths, e.g. `"skills/tdd"` |
| `agents` | string[] | Agent file paths, e.g. `"agents/reviewer.jsonc"` |

## Modes

Modes filter which resources are included in compiled output. They restrict — they don't add.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | yes | Machine-readable identifier. Pattern: `^[a-z0-9-]+$` |
| `name` | string | yes | Human-readable name |
| `description` | string | no | What this mode is for |
| `mcp_servers` | string[] | no | MCP server IDs to include (others excluded) |
| `skills` | string[] | no | Skill IDs to include |
| `rules` | string[] | no | Rule IDs to include (matched by filename stem) |
| `permissions` | object | no | Permission overrides (`allow`, `deny` arrays) overlayed on agent permissions |
| `target_agents` | string[] | no | Override the project's providers list |

## Example

```jsonc
{
  "$schema": "https://raw.githubusercontent.com/madvib/ship/main/schemas/ship.schema.json",
  "id": "abc123",
  "project": {
    "providers": ["claude", "gemini"]
  },
  "module": {
    "name": "github.com/owner/repo",
    "version": "0.1.0",
    "description": "Agent skills for code review",
    "license": "MIT"
  },
  "dependencies": {
    "github.com/acme/toolkit": "^1.0.0"
  },
  "exports": {
    "skills": ["skills/code-review"],
    "agents": ["agents/reviewer.jsonc"]
  }
}
```
