# Schema Reference

All Ship configuration uses JSONC (JSON with comments). Each config file supports a `$schema` field for editor autocompletion and validation.

## .ship/ directory layout

```
.ship/
  ship.jsonc              # Project manifest
  ship.lock               # Dependency lockfile (tool-authored JSONC)
  permissions.jsonc        # Permission presets
  mcp.jsonc               # MCP server definitions
  agents/
    <id>.jsonc            # Agent profiles
  skills/
    <skill-id>/
      SKILL.md            # Skill content with YAML frontmatter
      assets/
        vars.json         # Typed variables (optional)
      references/docs/    # Reference material (optional)
      scripts/            # Executable scripts (optional)
  rules/                  # Shared rule files (.md)
  pipelines/
    <name>.jsonc          # Workflow templates
```

Compiled output (CLAUDE.md, .mcp.json, .cursor/, .gemini/, .codex/, .agents/) is generated by `ship use` and gitignored.

## Schema URLs

| File | Schema URL |
|------|-----------|
| ship.jsonc | `https://raw.githubusercontent.com/madvib/ship/main/schemas/ship.schema.json` |
| agents/*.jsonc | `https://raw.githubusercontent.com/madvib/ship/main/schemas/agent.schema.json` |
| permissions.jsonc | `https://raw.githubusercontent.com/madvib/ship/main/schemas/permissions.schema.json` |
| mcp.jsonc | `https://raw.githubusercontent.com/madvib/ship/main/schemas/mcp.schema.json` |
| SKILL.md frontmatter | `https://raw.githubusercontent.com/madvib/ship/main/schemas/skill.schema.json` |
| assets/vars.json | `https://raw.githubusercontent.com/madvib/ship/main/schemas/vars.schema.json` |
| pipelines/*.jsonc | `https://raw.githubusercontent.com/madvib/ship/main/schemas/pipeline.schema.json` |

Add `$schema` to any config file for inline validation:

```jsonc
{
  "$schema": "https://raw.githubusercontent.com/madvib/ship/main/schemas/ship.schema.json",
  // ... rest of config
}
```
