# Ship Internal Development

How to set up the development environment, navigate the codebase, run tests, and follow Ship's engineering standards. For the team building Ship itself.

Ship does not currently accept external contributions. The path to that opens up post-launch, at which point this skill expands to cover PR process, contributor agreement, and review flow.
