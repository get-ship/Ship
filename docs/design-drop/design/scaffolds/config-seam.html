The config seam — Space ↔ Studio

Thin settings live in the space; the catalog and authoring live in Studio. A space holds instances — what's active, arranged, lightly tuned. Studio is the editor you open (like Settings, or Notepad on a config file) to author a reusable artifact or install one from your library. Only two verbs cross the seam. No cross-space anything — except Studio opened standalone, which is Shell.

Studio

A Shell surface that holds the library (the catalog) and the authoring IDE. Opened to edit, then returned from — not a place you live.

Shell · cross-space allowed here only
