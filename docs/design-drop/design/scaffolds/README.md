# scaffolds/

The 2 host scaffolds + chrome composition — cross-cutting surfaces that wrap
every view. Not tied to a single service, so they live here rather than under
`domains/`. Truth for shipped chrome is the read-only `chrome/` mirror at repo root.

- **spaces/** — spaces / hub scaffold. Open `interaction-model.html`.
- **shell/** — shell scaffold (rail · nav · dock). `mock.html`, `nav-frame.html`.
