Summarize Leads

Roll the current leads collection into a concise weekly digest the team can skim in under a minute.

When to use

Trigger this when asked for a pipeline summary, a weekly update, or "how are leads looking". Reads ship.collections.leads; never writes.

Steps

  • Read the leads collection for the active window (default: 7 days).
  • Group by stage; compute counts, week-over-week delta, and top sources.
  • Surface the 3 warmest leads by score with a one-line reason each.
  • Render a board artifact or hand back markdown — ask which.

Output

A short digest: headline number, delta, stage breakdown, and the warm list. Keep it to ~120 words unless asked to expand.
