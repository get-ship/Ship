A session is a render of its journal, not a chat log. The complete pack — 11 components + 2 atoms across @ship/agents and @ship/authority. The dense surfaces now read clean by default and disclose detail on demand (op-card hides its args; the approval prompt collapses to the ask + the verbs). Same parts compose every surface — fleet, op, gate, controls, the Agent Canvas. All compiled live from .sui, tokens only; code-ready spec in handoff.md. Switch themes at right.
