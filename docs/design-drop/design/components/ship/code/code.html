code-editor · terminal · git-diff

The @ship/code surfaces. The feature tier wraps heavy engines (CodeMirror, xterm); the chrome around each — tab strips, gutters, status bars, diff panes — is what's designed here, authored as token-pure SUI so it stays theme-reactive. The engine's own render area is mocked with realistic content. Syntax + ANSI colors map to ship tone tokens (no hex), so they re-theme. Switch themes at right — try console.

CodeMirror

Tab strip (active file + dirty dot), a line-number gutter with an active-line highlight, the token-colored editor body (the CodeMirror mount), and a status bar (branch · language · Ln/Col · indentation · encoding).

ship-terminal

xterm

Title bar with a session tab + split/new-tab actions, the framed scrollback (the xterm canvas) with tone-mapped output (ok · warn · fail · paths), a block cursor, and a status line (cwd · shell · size · encoding).

ship-git-diff

diff

File header (path + add/del stat badge + a Split/Unified toggle), a hunk header, and a side-by-side grid where removed cells tint --tone-destructive-bg and added cells --tone-success-bg, with per-side line numbers.
