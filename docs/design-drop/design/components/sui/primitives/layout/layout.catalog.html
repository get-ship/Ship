layout primitives

The canonical layout set. sui-stack (vertical) and sui-cluster (horizontal, wrapping) render as the real compiled elements, ported verbatim from _repo-src. Existing = the hand-rolled display:flex; gap:12px a view writes inline today — one magic number, no align/justify vocabulary, so every demo collapses to the same fixed gap. New = the token-driven primitive that honours the gap scale and align/justify props. Toggle Existing / New and watch the gaps and alignment come alive · switch themes right.
