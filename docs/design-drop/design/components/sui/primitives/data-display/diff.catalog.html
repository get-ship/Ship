sui-diff

Line diff viewer — live, not a screenshot. The element below is the real compiled sui-diff: its controller (ported verbatim from source) runs the actual LCS line-diff in the browser — pure JS, no daemon. The row structure (.line.add/.del/.ctx/.hunk + a .sign gutter) is ground truth from the controller; the styling is authored here, which is the gap this fills. Existing = the flat rendering a view gets with no design pass (colored text only); New = row tints, an accent gutter, and a hunk band. Toggle Existing / New · switch themes right.
