sui-draw

The freehand draw layer — the third canvas surface alongside canvas and board. The drawing area is a PixiJS engine at runtime (mocked here as a dotted grid); the design is the floating tool palette. Existing = a bare canvas with a plain tool row; New = a floating pill palette with a tool group, colour swatches, and stroke widths. Toggle Existing / New · switch themes right.
