01 Spaces

Every app, its own window.

Ship apps don't live in a tab. The host launches each one as a real OS window — with its own dock icon, its own spotlight entry, its own theme, its own identity. Cmd-tab to your agent. Pin it to the dock. Make it yours.

One space, one purpose

Writing app, dev project, marketing dashboard — each gets its own window, its own dock tile, its own state. No more 47 tabs pretending to be apps.

Native OS citizen

Registered with Spotlight and the launcher. Drag files in, copy results out. The OS already does focus well — Ship doesn't try to reinvent it.

Each one persists

Restart your machine; your spaces are right where you left them. Window positions, theme, scroll. It's ~/Spaces/ on disk and your own to back up.

02 Trust

Agents you can actually trust.

Every elevated action — reading a file, hitting the network, running a shell command — flows through the hub. You see what they want, why, and for how long before they get it. No silent rm -rf. No quiet network call. No "agent went rogue."

Capabilities as data

Every right an agent holds is a typed grant: fs:read, net, shell. Issued by you, revocable in one click, attached to the agent that asked.

High-risk gets the room it deserves

git push --force. Spending real money. Sending mass email. These don't slide past in a toast — they get a full-page review with diff, scope, and your authentication.

Every decision is replayable

Approvals, denials, auto-allowed-by-policy — all logged. Audit the agent that touched your repo. Set policy for next time.

05 Two-window editing

The hub edits. The space lives.

A space window runs the app — the real thing, the one you ship. A hub window holds the source — the file tree, the editor, the inspector. Save the file; the space window updates. No reload. No "let me restart it."

Edits stream in under 16ms

Change a token, the space repaints. Add a node to a pipeline, the next run picks it up. Hot reload that doesn't lie.

Works for everything in Ship

Space chrome. Pipelines. Skills. Agents. Themes. Same pattern, every primitive — the hub holds the file, the space shows the result.

Same source. Editor's choice.

Vim, VS Code, Cursor, the in-Ship Studio — any of them. The source on disk is the truth. Use what you already know.

06 Roadmap

And we're just getting started.

What's shipping now, what's next, what's still smoke and napkins.

Spaces
Now

Host-launched windows. Each space its own theme + identity. macOS shipping; Linux + Windows next.

Capability model
Now

Typed capabilities, hub-issued grants, full decision log. Every agent action accounted for.

7 themes
Now

ship-light, ship-dark, paper, halo, console, contrast, glass. Plus density + chrome controls.

Multi-agent orchestration
Next

Agents that hand off, ask each other for help, run in parallel. Backed by the same capability model.

Marketplace
Next

Spaces, skills, themes, pipelines you can install in one click. Every install routes through Authority.

Sync
Next

Your spaces, your agents, your decisions — across devices. Event log first, conflict-free.

Custom chrome
Later

Replace the entire window body. Make a space look like a terminal, a canvas, a notebook — whatever it should be.

Peer-to-peer trust
Later

Macaroon-style delegation. Send a scoped grant to a teammate's space; they run, you don't share the keys.

Cloud compute
Later

Same capability semantics, somewhere with more cycles. Your laptop offloads; your trust model doesn't move.
