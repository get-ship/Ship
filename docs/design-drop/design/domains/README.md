# domains/

The spine. One folder per platform service. Each completed service lands a
**handoff** here: copy `_TEMPLATE/` → `<service>/` and fill `handoff.md`.

Everything for a job lives in its folder — handoff contract, fixtures, domain
pack, optional view, and the UX mocks. See [`../INDEX.md`](../INDEX.md) for the
full workflow and the domain roster / work queue.

`_TEMPLATE/` is the starting point — don't edit it in place, copy it.
