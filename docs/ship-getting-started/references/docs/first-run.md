The first time you launch Ship, the app opens in your browser at `http://127.0.0.1:9315/`. A short setup walks you through three things:

1. **Welcome** — orients you. Ship runs entirely on your machine.
2. **Pick a project folder** — start a new project or open an existing one. Ship sets up the project workspace.
3. **Connect a provider** — pick Claude, Gemini, Codex, Cursor, or OpenCode and paste an API key. You can skip this and connect later.

That's it. After setup you land on the dashboard.

## If the browser doesn't open

Visit `http://127.0.0.1:9315/` directly.
