The Ship Store is the next iteration of the registry — a place to browse, install, and publish skills, agents, pipelines, and views. We're evolving the existing package system into the Store; install and publish work today, but the public-facing experience is being built.
</sui-alert>

The Ship Store will host community and first-party packages: skills, agents, pipelines, views, themes, and collections. Every package is a Git repo with a `.ship/` directory; every dependency is pinned in `ship.lock` with the exact commit and SHA-256 tree hash.

Public docs for installing and publishing land alongside the Store.
