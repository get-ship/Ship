> **Scaffold** — Ship Cloud is the optional paid layer, not yet open. This page is a placeholder until it ships.

Ship is [local-first](/docs/local-first/): everything works on your machine with no account. Cloud is an opt-in layer on top, not a hosting model that owns your data. When it lands it adds:

- **Sync** — replicate a space's event log across your machines.
- **Teams** — share a space with collaborators; changes show up live.
- **The Store** — install and publish components (skills, agents, views) as packages.

Pricing and availability arrive with the public beta's paid tier.
