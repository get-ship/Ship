All macros live in `apps/shipd/templates/_ship.html.j2` and are
imported from it. The canonical spec is
`packages/ship-set/sdk/sdk-macros.json`, regenerated by `just gen-sdk`
and served live at `GET /api/runtime/sdk`.

For deeper discussion of a primitive — when to use it, anti-patterns,
examples — see [Primitives](./primitives.md).

## Page setup

| Macro | Signature | Purpose |
|---|---|---|
| `head` | `head(title='Ship View')` | Standard `<head>` contents (meta, title, tokens, Datastar, ship-elements). Emits nothing in fragment mode. |
| `styles` | `styles()` | Shared utility styles used by `form()` and `table()`. Place once in `<head>` when rendering an auto-form or auto-table. |

## Signals and reactivity

| Macro | Signature | Purpose |
|---|---|---|
| `signal` | `signal(name, default='')` | Declare one reactive signal. |
| `signals` | `signals(fields)` | Declare many signals from a dict. Emits type metadata for AST-lint. |
| `show` | `show(expr)` | Hide element until expr truthy. No flash. |
| `toggle_class` | `toggle_class(cls, expr)` | Reactive single-class toggle. |
| `attr` | `attr(name, expr)` | Reactive attribute value. |

## SSE and live updates

| Macro | Signature | Purpose |
|---|---|---|
| `live` | `live(view_name)` | Subscribe element to the view's SSE stream. |
| `live_persistent` | `live_persistent(view_name)` | Like `live()` but survives `@get`/`@post` cancellations. |
